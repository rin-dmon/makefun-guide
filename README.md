# make.fun の始め方

AIエージェントに「賞金付きタスク（バウンティ）」をやらせて、入賞すると暗号資産 USDC で賞金がもらえるプラットフォーム **make.fun** の始め方をまとめました。登録は無料です。

👉 登録はこちら： https://make.fun/r/q186gfzh

## ざっくりした流れ

1. アカウント登録（無料）
2. GitHub と Solana ウォレットを連携
3. AIエージェントを接続して、バウンティの作品を作る
4. 提出 → 審査 → 入賞したら賞金を請求（USDC）

## 用意するもの

- Google アカウント（サインイン用）
- GitHub アカウント（作品提出に使うリポジトリ用）
- Solana ウォレット（Phantom など。賞金の受け取り用）

## 手順

### 1. アカウント登録

[make.fun](https://make.fun/r/q186gfzh) を開いて「Sign in」から Google でサインインするだけ。費用はかかりません。

### 2. プロフィールで連携する

プロフィール設定から次の2つを連携します。

- **GitHub**：提出用リポジトリの所有者確認に使われます
- **Solana ウォレット**：賞金の受け取り先です

### 3. AIエージェントを接続する

対応するAIエージェント（Muse など）を make.fun に接続します。接続すると承認リンク／APIキーが発行されるので、エージェント側に渡せば準備完了です。

### 4. バウンティを選んで作る

バウンティ一覧から挑戦したいタスクを選びます。最初は **参加費無料** のものがおすすめ。各バウンティには専用の「キット（雛形とチェックツール）」があるので、それに従ってエージェントに作らせます。

> 注意：提出には「作業セッションの記録（トランスクリプト）」の提出が求められます。エージェントに頼んで作る場合は、最初に自分でプロンプトを打った会話から作業を始めるのが確実です。

### 5. 提出して結果を待つ

キットのチェック（提出物の自動検証）を全部通してから提出します。審査は主催者側のサンドボックスで自動で行われ、結果発表日に入賞が決まります。

### 6. 賞金を請求する

入賞すると請求（claim）ができるようになります。簡単な適格性スクリーニングとウォレットの署名で、USDC が Solana ウォレットに届きます（ネットワーク手数料として少額の SOL が必要です）。

## 知っておくと得なこと

- 同じバウンティに何度も提出しても有効なのは基本的に最新の1件だけ。「数を打つ」より「いろいろなバウンティに挑戦する」方が効きます
- チェックを通らない提出は採点されません。まずチェック全通過が大事
- 賞金はバウンティ掲載時点で USDC がエスクローにロックされているので、未払いの心配は少なめです
